# HTML, CSS Practice Course

This is a super simple practice project on plain HTML and CSS. The project comprises of two folders:
1. intro-to-html showing all the rough work and practice. It contains html files with in-built styling, and a style css file.
2. youtube-recreation: a crash project recreating YouTube's home page, just to better practice what has been learned. It is organized into an index.html file for structuring, a styles folder containing all the styling files, and an images folder sontaining all the images used.
